## Новый акцентный слайд №20

### Слайд 20. Современная геоцентрическая модель плоской Земли (Modern Flat Earth)

**Заголовок:** _Современная плоская Земля: геоцентрическая модель_

**Текст на слайде (максимум 50 слов):**

> Земля — плоский диск (обычно с Арктикой в центре и ледяной стеной Антарктиды по краю). Солнце и Луна — небольшие светила (диаметром ~50 км), движущиеся по кругу над плоскостью Земли. Вселенная вращается вокруг Земли. Звёзды — на твёрдом куполе (или множество маленьких светил). Гравитация не признаётся — предметы падают вниз из-за постоянного ускорения диска вверх (~9.8 м/с²).

**Ключевые элементы (для справки):**

| Элемент             | Описание в современной плоской модели                                                              |
| ------------------- | -------------------------------------------------------------------------------------------------- |
| **Форма Земли**     | Плоский диск (азимутальная проекция: Северный полюс в центре, Антарктида — ледяная стена по кругу) |
| **Солнце и Луна**   | Маленькие, близкие, движутся по кругу над диском, создавая день/ночь (как прожектор)               |
| **Звёзды**          | Либо на твёрдом куполе, либо множество маленьких светил на вращающейся плоскости                   |
| **Гравитация**      | Заменена на ускорение диска вверх (теория универсального ускорения)                                |
| **Космос**          | Не существует как внешнее пространство — вся вселенная ограничена куполом или плоскостью           |
| **Геоцентричность** | Земля — центр всего мироздания (в отличие от гелиоцентрической модели)                             |

**Происхождение современной модели:**

| Время  | Фигура / Организация                           | Вклад                                                                                   |
| ------ | ---------------------------------------------- | --------------------------------------------------------------------------------------- |
| XIX в. | Сэмюэл Роуботэм (Samuel Rowbotham)             | Книга «Zetetic Astronomy: Earth Not a Globe» (1865) — основа современной плоской модели |
| 1956   | Сэмюэл Шентон (Samuel Shenton)                 | Основал «International Flat Earth Research Society»                                     |
| 2004   | Дэниел Шентон (Daniel Shenton, не родственник) | Возрождение движения в интернете (The Flat Earth Society)                               |
| 2010+  | YouTube, соцсети                               | Широкое распространение модели в интернете                                              |

**Изображение для слайда (рекомендации):**

| Вариант                                            | Что показывает                                                                                               | Поисковый запрос                            |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | ------------------------------------------- |
| **Азимутальная карта плоской Земли**               | Диск с Северным полюсом в центре, Антарктида — ледяная стена по краю, Солнце и Луна в виде кругов над диском | `flat earth azimuthal map sun moon path`    |
| **Схема «прожекторного солнца»**                   | Маленькое солнце движется по кругу над диском, создавая зоны дня и ночи                                      | `flat earth spotlight sun diagram`          |
| **Иллюстрация ускорения (universal acceleration)** | Стрелки, показывающие ускорение диска вверх                                                                  | `flat earth universal acceleration diagram` |

**Рекомендую:** азимутальную карту с обозначенной траекторией солнца — это наиболее узнаваемое и наглядное изображение для современной модели.
